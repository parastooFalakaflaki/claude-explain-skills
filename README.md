# Claude explain skills

Personal Claude Code skills, a subagent and an output style that make Claude explain a codebase in plain sentences and link each claim to the code.

## Install

Open Claude Code on the machine where you want these, and paste this:

```text
Clone https://github.com/parastooFalakaflaki/claude-explain-skills into ~/code/claude-explain-skills, then read INSTRUCTIONS.md there and follow its install steps.
```

To install without a model, run `bash install.sh` from this folder, add `"outputStyle": "Plain explainer"` to `~/.claude/settings.json`, and restart Claude Code.

[INSTRUCTIONS.md](INSTRUCTIONS.md) has the full steps, the list of commands, and the known limits.

This repository is on a personal account, so keep company code, data and writing samples out of it.
